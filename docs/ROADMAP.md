# Project Roadmap

## 목적

이 문서는 `Customer Support Agent` 프로젝트의 상위 수준 진행 방향과 주요 개발 단계를 정의합니다.

프로젝트 목표에 도달하기 위해 거쳐야 할 주요 이정표와 단계 간 진행 순서를 제시하여, 개발 과정에서 현재 작업의 우선순위와 프로젝트 범위가 전체 목표에 부합하는지 판단하는 기준으로 사용합니다.

로드맵은 프로젝트 진행 과정에서 새롭게 확인된 정보와 변경된 우선순위를 반영하여 수정할 수 있습니다.

세부 구현 방식과 개별 작업은 이 문서에서 정의하지 않습니다.

## 프로젝트 목표

주문 관련 고객 문의를 처리하는 `Tool Calling` 기반 `Customer Support Agent`를 구현하고, `Agent`의 실행 과정을 평가·관측하며 실제 실행 가능한 환경에 배포합니다.

이 과정을 통해 `Tool Calling`, `Agent Loop`, `Tool` 실행 및 오류 처리, `Evaluation`, `Observability`로 이어지는 `Agent` 애플리케이션의 핵심 실행 구조를 이해하고, 동작을 직접 검증하고 개선할 수 있는 수준의 엔지니어링 역량을 확보하는 것을 목표로 합니다.

## 진행 단계

### 1. Tool Calling Agent Loop 구현

#### 목표

하나의 `Tool`을 사용하는 최소 `Agent Loop`를 구현하여, 모델의 `Tool Call`을 애플리케이션에서 처리하고 `Tool` 실행 결과를 다시 모델에 전달해 최종 응답까지 이어지는 기본 실행 흐름을 확보합니다.

#### 완료 기준

- 모델이 사용자 요청에 따라 정의된 `Tool`을 호출할 수 있습니다.
- 애플리케이션이 `Tool Call`의 입력을 검증하고 해당 `Tool`을 실행할 수 있습니다.
- `Tool` 실행 결과가 모델에 다시 전달되고 이를 반영한 최종 응답이 생성됩니다.
- `Agent Loop`의 반복 및 종료 조건이 애플리케이션에서 제어됩니다.

### 2. Customer Support Agent 구현

#### 목표

기본 `Agent Loop`를 확장하여, 주문 관련 고객 문의에 필요한 정보를 Tool을 통해 조회하고 조회 결과에 따라 적절한 응답을 생성하는 `Customer Support Agent`를 구현합니다.

#### 완료 기준

- `Agent`가 고객 문의에 따라 필요한 `Tool`을 선택하고 사용할 수 있습니다.
- 고객, 주문, 정책 등 응답에 필요한 정보를 `Tool`을 통해 조회할 수 있습니다.
- 조회된 정보를 근거로 주문 관련 고객 문의에 대한 응답을 생성할 수 있습니다.
- 정보 부족, 유효하지 않은 입력, `Tool` 실행 실패 등 정의된 예외 상황을 처리할 수 있습니다.
- `Agent`의 최종 결과가 정의된 출력 형식으로 반환됩니다.

### 3. Evaluation & Observability 구축

#### 목표

`Customer Support Agent`의 동작을 반복적으로 평가하고 개별 실행 과정을 추적할 수 있도록 `Evaluation`과 `Observability` 체계를 구축합니다.

#### 완료 기준

- 대표적인 고객 문의와 기대 동작으로 구성된 `Evaluation Dataset`이 존재합니다.
- `Agent`의 핵심 동작과 최종 결과를 평가할 수 있는 기준이 정의되어 있습니다.
- 동일한 `Evaluation Dataset`을 반복 실행하여 `Agent`의 결과를 비교할 수 있습니다.
- `LLM` 호출과 `Tool` 실행을 포함한 `Agent`의 실행 과정을 `Trace`로 확인할 수 있습니다.
- 실패한 `Evaluation` 결과와 해당 실행 `Trace`를 연결하여 원인을 조사할 수 있습니다.

### 4. Failure Analysis 및 반복 개선

#### 목표

`Evaluation` 결과와 `Trace`에서 확인된 실패를 체계적으로 분석하고, 분석 결과에 근거한 변경과 재평가를 통해 Agent의 동작을 개선합니다.

#### 완료 기준

- `Evaluation`에서 발생한 주요 실패 유형이 식별되어 있습니다.
- 대표적인 실패 사례에 대해 원인과 관련 실행 단계가 분석되어 있습니다.
- 분석 결과에 근거한 개선 사항이 적용되어 있습니다.
- 동일한 `Evaluation Dataset`으로 변경 전후 결과를 비교할 수 있습니다.
- 적용한 변경이 해결하려던 실패에 어떤 영향을 주었는지 설명할 수 있습니다.

### 5. 배포 및 완료 검증

#### 목표

`Customer Support Agent`를 개발 환경 외부에서 실행 가능한 형태로 배포하고, 프로젝트에서 정의한 기능과 엔지니어링 목표의 달성 여부를 최종 검증합니다.

#### 완료 기준

- `Customer Support Agent`가 배포 환경에서 실행됩니다.
- 배포 환경에서 대표적인 고객 문의와 주요 예외 시나리오가 정상적으로 처리됩니다.
- `Evaluation`과 `Observability`가 배포된 시스템에서도 필요한 수준으로 동작합니다.
- 프로젝트에서 정의한 기능 범위가 충족되었음을 확인합니다.
- `Agent`의 실행 구조, 평가 결과, 주요 실패와 개선 과정을 설명할 수 있는 상태에서 프로젝트를 종료합니다.
